# interaction — 스크롤 연출 · 발색 비교 · 씬 파라미터

담당: **조수희**

작업 규칙은 [`AGENTS.md`](AGENTS.md). **작업은 팀장이 올린 이슈로만 시작한다.**

## 무엇을 만드는 곳인가

기획서 5-2 "인터랙션·제품 시각화"의 웹 부분이다.

| 만드는 것 | 어디에 쓰이나 |
|---|---|
| 스크롤 연출 | 메인(`/`) — 스크롤에 따라 태양이 움직이고 스토리 보드로 넘어가는 구간 |
| 발색 비교 | 제품 상세(`/collection/[slug]`) — 같은 팔찌·목걸이의 실내(흰색)와 햇빛(발색) 모습 비교 |
| 씬 파라미터 | 메인 3D 장면의 색 · 속도 · 카메라 경로 값 묶음 |

**구체적인 작업과 순서는 이슈가 원본이다.** 이 표는 범위만 적는다.

## 3D는 순서가 있다

봉준표가 `components/scene/`에 WebGL 뼈대(태양 셰이더 · 씬 구조 · 보드 좌표)를 먼저 만든다. 조수희는 그 **공개 부품** 위에 스크롤 연출과 파라미터를 얹는다. 셰이더와 씬 구조는 고치지 않는다.

| 가져다 쓰는 부품 (`components/scene/`) | 상태 |
|---|---|
| 태양 · 씬 · 보드 공개 부품 | 뼈대 이슈에서 만든 뒤 이 표에 이름과 props를 적는다 |

## 테스트

`frontend/e2e/interaction/` — 이 폴더의 부품이 들어간 페이지가 열리고, 움직임을 줄이는 설정(`prefers-reduced-motion`)에서 정적 화면이 나오는지 확인한다.

## 먼저 볼 교재

`web-demo/`를 실행하고 아래 순서로 읽는다. 각 페이지는 **결과 화면 → 코드에서 볼 곳 → 전체 코드** 순서다.

| 순서 | 페이지 | 이 폴더와의 관계 |
|---|---|---|
| 1 | `/scrolltrigger` | 스크롤 위치를 애니메이션 진행도로 바꾸기 — 스크롤 연출의 기본 |
| 2 | `/splittext` | 문장을 글자·단어로 쪼개 움직이기 — 스토리 문구 연출 |
| 3 | `/r3f` | React로 조립한 3D 장면 — 씬 파라미터를 넘기는 방식 |
| 4 | `/three` | 같은 장면을 순수 Three.js로 — 뼈대 안에서 무슨 일이 일어나는지 |
