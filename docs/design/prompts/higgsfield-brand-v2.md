# SUNNY — Higgsfield AI용 제작 프롬프트

## 브랜드 방향 — v2
SUNNY는 팔찌와 목걸이를 전개하는 브랜드다. 단일 팔찌 광고나 과학 교육 영상이 아니라 성숙한 주얼리 브랜드를 위한 감성 소스를 제작한다. 아래 태양 영상에 제품을 넣지 않는 것은 제품군을 제외한다는 뜻이 아니라, 브랜드 상징 소스와 제품 화보를 분리한다는 뜻이다.
태양은 캐릭터가 아니라 빛의 근원이다. 동화·장난감·게임·SF 예고편처럼 보이지 않게 한다. 이미지 완성도는 눈부신 효과보다 명암과 질감, 움직임의 절제로 만든다. 노란 플라스틱 구체, 과도한 주황 채도, 금박 느낌, 귀여운 얼굴, 비즈 궤도, 마법 입자를 배제한다.

## 사용 목적
웹사이트 전체를 생성하는 프롬프트가 아니라 A안 히어로에 합성할 태양 영상 소스 제작용이다. 태양의 측면 이동, 중앙 정렬, 확대, 스토리보드 연결은 Claude Code가 구현한다. 이 분리가 재생성 비용과 스크롤 제어 문제를 줄인다.

처음에는 아래 공통 프롬프트로 ‘고정된 태양 원반’ 1개만 테스트한다. 16:9, 5초 내외, 720p 또는 1080p 초안으로 시작하되 현재 선택 모델이 지원하는 설정을 사용한다. 길이·비율·해상도는 UI에서도 직접 설정한다. 특정 모델의 참조 이미지, 시작/끝 프레임, 무제한 기능을 지원한다고 가정하지 않는다. 결과 확인 후 최종 후보만 고해상도로 제작한다.

## 메인 프롬프트 — 태양 원반 소스
아래 전체를 생성 입력창에 붙여 넣는다.

검은 배경 위에 단 하나의 태양 원반이 있는 성숙한 컨템포러리 주얼리 브랜드를 위한 절제된 태양 영상 소스를 제작한다. 완성된 웹페이지나 포스터가 아닌, 웹 개발자가 합성할 순수 영상 에셋이다.

캔버스는 가로 16:9. 카메라는 완전히 고정한다. 줌, 팬, 틸트, 돌리, 롤, 궤도 이동, 카메라 흔들림이 없다. 태양의 중심은 정확히 화면 중앙에 고정되고 원반의 크기와 원형 실루엣은 전체 영상 동안 일정하다. 태양 지름은 화면 높이의 약 64~68%이며 태양 주변에는 크롭과 웹 합성을 위한 넉넉한 검은 여백을 둔다. 코로나의 가장 바깥 부분도 프레임 끝에 닿지 않는다.

태양은 단단한 행성이나 용암 구체가 아니라 빛을 내는 플라스마로 표현한다. 조밀한 필라멘트, 작은 밝기 차이, 얇고 섬세한 가장자리 발광, 절제된 자기장 루프에서 영감을 받은 구조를 사용한다. 활동은 매우 느리고 차분하며 표면 내부에서만 일어난다. 몇 초 만에 한 바퀴 도는 회전은 없다. 거대한 폭발이나 태양에서 튀어나와 화면을 덮는 불기둥은 없다.

팔레트는 낮은 채도의 호박색, 절제된 금빛, 소량의 적갈색, 가장 밝은 부분의 연한 아이보리다. 색은 브랜드를 위한 예술적 표현이며 실제 가시광 태양의 색을 재현한다고 주장하지 않는다. 어두운 부분에도 미세한 구조를 남기고 밝은 부분은 디테일이 보존되도록 한다. 과도한 bloom이나 하얗게 날아간 중심부는 피한다. 배경은 매끈한 검정이며 별, 은하, 먼지, 성운, 렌즈 플레어, 필름 그레인으로 채우지 않는다.

감정은 위험, 재난, 폭발이 아니라 따뜻함, 경외감, 조용한 연결감이다. 주제는 ‘태양과 교감한다’. 고급 브랜드 필름처럼 절제되고 촉각적으로 섬세한 느낌을 준다. 시작과 끝의 구도, 원반 크기, 전체 밝기는 매우 유사하게 유지하고 편집용 짧은 루프에 적합한 잔잔한 움직임을 지향한다. 완벽한 루프가 모델에서 보장되지 않더라도 마지막에 페이드아웃이나 카메라 이동을 추가하지 않는다.

텍스트, 로고, NASA 표식, 타임스탬프, 파장 숫자, 자막, 워터마크를 의도적으로 그리지 않는다. UI, 버튼, 웹페이지 프레임, 노트북, 휴대폰 목업을 넣지 않는다. 사람, 손, 눈, 얼굴, 팔찌, 제품, 지구, 달, 다른 천체를 추가하지 않는다. 대기 중의 모닥불, 연기, 물결, 용암 균열, SF 포털, 태양의 표정을 만들지 않는다. 오디오가 기본 생성되더라도 웹에서는 사용하지 않을 무음 배경 소스다.

실제 NASA 촬영물이라고 주장하지 않는 예술적 시각화다. 제공한 NASA 참조 이미지가 있다면 관측된 필라멘트 구조와 질감의 참고로만 사용하고, NASA 로고·문자·날짜·관측 라벨을 결과에 재생성하지 않는다. 원본 사진을 그대로 보존한 관측 데이터처럼 보이게 만들지 않는다.

## 두 번째 소스가 필요할 때만: 표면 근접 버전
위 메인 프롬프트의 ‘캔버스와 태양 원반’ 및 ‘시작과 끝’ 문단 대신 아래를 사용한다. 별도 영상으로 생성하며 원반 버전과 한 번에 요청하지 않는다.

화면 전체를 태양 플라스마의 가까운 질감으로 채운다. 가장자리 원반이나 우주 배경은 보이지 않는다. 카메라는 완전히 고정되고 표면의 미세한 필라멘트만 아주 느리게 움직인다. 호박색과 금빛의 밝기 층을 유지하고 중앙 영역에 비교적 부드러운 질감을 둔다. 화면 구석까지 연속적인 질감이 이어지며 눈에 띄는 반복 패턴이나 대칭 무늬가 없다. 이것은 다이브 전환 때 짧게 합성할 배경 소스다. 폭발, 진입 카메라, 암전, 흰색 섬광, 자막을 직접 생성하지 않는다. 전환은 웹 코드가 처리한다.

## 참조 이미지 준비와 출처
- 추천 참고: NASA/SDO AIA 171 Å(구조·금빛 방향), AIA 304 Å(가장자리·채층 구조 참고).
- 참조가 있다면 원본 출처, 다운로드 시각, 확인 가능한 관측 시각, 사용 채널을 별도 기록한다.
- 같은 확정 원본과 팔레트를 유지해서 후보 사이 일관성을 높인다.
- 생성 결과는 ‘AI 기반 예술적 시각화’로 관리한다. NASA 관측 카드에는 넣지 않는다.
- NASA 자료의 이용 조건과 Higgsfield 선택 모델의 참조 업로드·상업적 이용 조건을 각각 확인한다. 이 문서는 업로드 권리나 출력 이용 권리를 보증하지 않는다.

## 제작·검수 체크리스트
1. 저해상도 원반 후보 3개부터 만든다. 한 번에 수십 개를 만들지 않는다.
2. 밝기와 질감이 좋은 한 후보를 고른 뒤 웹에 실제로 넣어 본다.
3. 태양 원반의 중심·크기 흔들림, 클리핑, 깜빡임, 비정상 회전을 검사한다.
4. 배경 검정은 생성 결과에서 정확한 RGB가 아닐 수 있다. 필요하면 편집 단계에서 보정한다. 투명 알파가 생성된다고 가정하지 않는다.
5. 루프 연결은 실제 마지막/첫 프레임을 비교한다. 불연속이면 편집용 크로스페이드나 정적 포스터로 처리한다.
6. 원반 영상을 웹에서 과도하게 확대하면 해상도가 깨지므로 근접 구간을 별도 소스로 연결한다.
7. 모바일에서 태양이 잘리지 않도록 먼저 CSS 크기 조정을 검증한다. 필요할 때만 9:16 별도 생성한다.
8. 원본 마스터, 웹 압축본, 포스터를 분리한다. 최종 파일명 제안: sunny-solar-disc-master.mp4, sunny-solar-disc-web.mp4, sunny-solar-disc-poster.webp, sunny-solar-surface-web.mp4.
9. 모델명, 실제 생성 크레딧, 설정, 수정 이유, 선택 여부를 제작 로그에 기록한다.

NASA 관측 영상도 대안이다. 관측 자체의 타임랩스가 충분히 아름답다면 AI 영상을 추가하지 않아도 된다. 단, 관측 영상의 사용 시간 범위와 타임랩스 여부를 표기하고 실제 스크롤 다이브는 예술적 전환임을 구분한다.

## 후속 제품 화보 제작 원칙
팔찌와 목걸이는 동일한 조명·배경·색보정 체계 안에서 동등하게 다룬다. 단, 실제 제품 참조와 사양 승인 전에는 판매용 제품 이미지를 생성하지 않는다. AI가 만든 임의의 잠금장치·체인·소재·색을 실제 제품 사양으로 사용하지 않는다. 분위기 시안은 시안으로 표시한다. 제품 형태 보존이 중요한 최종 컷은 실물 사진을 우선한다. 이 프롬프트의 태양 소스에 팔찌나 목걸이를 추가해 동시에 만들지 않는다.
